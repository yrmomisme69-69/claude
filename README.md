# PRISM 直达按揭｜示范网站

2026 工行杯参赛项目「PRISM 直达按揭：银行内嵌的按揭申请与成本核对服务」的立项书与可操作原型。

- 默认简体中文（`docs/index.html`），右上角一键切换繁体（`docs/hant/index.html`），浏览器会记住选择。
- 纯静态网站：全部计算在浏览器内完成，不连接任何服务器、CDN、字体或统计服务。只要能打开网址就能用，也可以离线打开。
- 兼容较旧的手机、微信内置浏览器及国产浏览器（脚本只用 ES2017 语法）。
- 演示站只用合成资料，不取得报价、不作信贷审批、不提交申请。

## 上线（GitHub Pages，免费）

1. 把本分支合并到 `main`。
2. 打开仓库 **Settings → Pages**，**Source** 选 **Deploy from a branch**。
3. **Branch** 选 `main`，文件夹选 `/docs`，按 **Save**。
4. 一两分钟后网址为：`https://yrmomisme69-69.github.io/claude/`（繁体版在 `…/claude/hant/index.html`）。

> 想要更好看的网址：把仓库改名（例如 `prism`），网址就会变成 `https://yrmomisme69-69.github.io/prism/`。

### 备用网址（可选，Cloudflare Pages）

github.io 在中国大陆大多可以打开，但有时较慢。可以多放一份作备用：登录 <https://dash.cloudflare.com> → **Workers & Pages → Create → Pages → Upload assets**，把整个 `docs` 文件夹拖进去，会得到 `xxx.pages.dev` 网址。

## 修改内容

网站只写一份繁体源文件（与立项书用字一致），简体版由程序自动转换：

```
site-src/page.html   页面结构及全部文字（繁体）
site-src/style.css   样式
site-src/app.js      计算及互动（繁体）
build.py             合并成单一 HTML，并用 OpenCC 生成简体版
```

改完后执行：

```
pip install -r requirements.txt
python3 build.py
```

然后把 `docs/` 一起提交。请不要直接修改 `docs/` 里的文件，下次 build 会被覆盖。

## 测试

```
python3 build.py
npm install playwright   # 如尚未安装
node tests/site.test.js
```

测试会在浏览器里逐项核对立项书的数字、四个展示案例、原型 App 全流程、语言切换及手机版面，并用 3000 组随机输入确认成本引擎与原版 v3 计算器（`tests/oracle_v3.js`）结果完全相同。
